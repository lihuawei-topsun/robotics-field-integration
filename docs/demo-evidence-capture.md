# 安防自主导航 Demo 最小证据拍摄清单

目标：用 30–45 秒真实素材证明“机器人能在一个安防场景中完成路线、检查点与回传闭环”。不追求宣传片质感，优先证明可运行、可复现、可人工接管。

## 必拍 5 段

### 1. 起点与任务（4–6 秒）

- 同一画面拍到机器人、起点和前方路线。
- 录到操作界面中的任务名称或路线选择；没有界面时，用纸质编号标出起点。
- 机器人从静止状态开始执行，不剪掉启动前状态。

建议文件名：`01-start-and-mission.mp4`

### 2. 自主行驶与避障（8–12 秒）

- 连续拍摄机器人沿路线移动。
- 若要展示避障，使用安全、可控的非人员障碍物；不要安排突然横穿的人。
- 保留一次减速、绕行或安全停止的完整过程，不只拍结果。

建议文件名：`02-navigation-and-obstacle.mp4`

### 3. 检查点到达（6–8 秒）

- 同时拍到机器人和明确的检查点标识。
- 展示到点后的停止、朝向调整和采集动作。
- 如果系统有到点状态，拍到真实状态变化；不要后期伪造状态文字。

建议文件名：`03-checkpoint-arrival.mp4`

### 4. 数据回传或异常复核（6–10 秒）

- 录屏展示相机画面、传感器结果、截图、告警或人工复核入口。
- 画面中时间和检查点应与第 3 段对应。
- 若当前只支持图像回传，就只展示图像回传，不写“自动识别”。

建议文件名：`04-data-return.mp4`

### 5. 人工接管与结束状态（4–6 秒）

- 展示暂停、停止或人工接管中的一种。
- 最后拍到机器人安全停止和任务结束状态。
- 证明系统有可控的失败/退出路径，而非只会启动。

建议文件名：`05-stop-or-handover.mp4`

## 可选证据

- 机械臂：只拍一个当前能稳定重复的动作，并展示动作前后状态。
- 建图：拍真实地图和机器人当前位置，不放与现场无关的仿真地图。
- 弱网或断连：展示系统如何停止或进入人工处理；不要在人员附近测试。
- 检查点重复：同一任务连续运行两次，比单次精彩镜头更有说服力。

## 隐私与安全检查

- 不出现客户名称、厂区门牌、敏感设备编号、Wi-Fi 名称、IP、账号、密钥或内部系统域名。
- 人员正脸、车牌、监控画面和客户 logo 必须获得授权或打码。
- 不展示武器、威慑性改装或人脸识别。
- 不让人员进入机器人规划路径，不用危险动作制造效果。
- 不写未测试的续航、准确率、防爆、防护等级或 24/7 能力。

## 最小交付

以下任一组合即可开始制作网站真实 Demo 区：

1. 上述 5 段原始视频；或
2. 1 段连续任务视频 + 3 张界面截图；或
3. 无法外传视频时，提供 6–10 张已脱敏连续截图，并标明先后顺序。

素材保持原始分辨率，不先加字幕、滤镜或音乐。后续网站版本只会添加事实标签、路线/检查点标识和必要的隐私处理。
