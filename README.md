# 现场机器人二次开发获客网站

面向宇树 G1 / Go2-W 二次开发、安防自主导航与机械臂集成的单页获客网站。

## 本地运行

```bash
npm install
npm run dev
```

## 询盘机制

表单不上传数据。访客填写后，页面会在本地生成结构化邮件，并打开默认邮件客户端发送到 `li.huawei@topsunpower.cc`。同时提供邮箱复制按钮。

## 事实边界

- 已有能力来自需求方原始描述：安防场景自主导航 Demo；可加机械臂。
- 页面内机器人图片为 AI 生成的视觉示意，不是客户现场或宇树产品实拍。
- 本网站为独立二次开发服务，不代表宇树官方。
