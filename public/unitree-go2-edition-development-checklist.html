02 / QUESTIONS

采购前的八个问题

  1. 01合同、发票与机身信息上的准确型号、地区版、硬件版本和出厂固件是什么？
  2. 02交付方承诺的“二次开发”具体指 App 图形化编程、WebRTC、SDK2、ROS2/DDS、SSH、低层控制中的哪些？
  3. 03机载与外置计算分别是什么，OS/架构/网卡如何，能否从干净环境重新部署？
  4. 04LiDAR、相机、IMU、odom 和 TF 的真实来源、topic、frame、频率与时间戳时钟是什么？
  5. 05App 的 3D 建图/巡逻是否等于开放 API，地图能否保存、重开、导出、冷启动定位和程序化下发航点？
  6. 06非零速度由哪个接口接收，命令是否有 TTL，发布者消失、网络断开和进程退出时如何确定停止？
  7. 07遥控器、App、SDK、planner 与机械臂谁拥有控制权，如何切换、取消、人工接管和重新解锁？
  8. 08售后支持的固件/SDK 组合、保修边界、日志导出、恢复流程与 RMA 条件是否写入交付材料？
03 / NO-MOTION

先做无动作能力清单

检查项需要记录不能替代的证据
通信面DDS/WebRTC/ROS2/API/SSH 的实际可用性、身份与版本仓库中存在示例，不代表该 SKU/固件开放。
状态LowState/SportModeState、API version、mode、错误码、原始 stamptopic 有名字，不代表数据新鲜或语义相同。
感知相机、点云、odom、TF 的来源、frame、频率、样本和静默超时App 能显示点云，不代表 ROS 可获得 raw LiDAR。
地图在线点云、静态导出、地图 ID/尺寸/完整性和重定位接口保存 PCD/PGM，不等于下次启动能定位与巡逻。
控制权遥控/App/SDK/planner 当前 owner、manual-only 与 STOP latch发送一次零速度，不等于 planner 不会恢复。
记录原始 bag/database hash、topic 时间范围、敏感信息清理记录演示视频不能替代可复现的状态时序。
04 / ACCEPT

实机交付五级门

版本冻结

记录 SKU、固件、SDK/代码 commit、计算、传感器与网络；后续结果只属于该配置。

CONFIG

只读证据

状态、相机、点云、odom 与 TF 连续、可重放；明确 topic silent 与 decoder failed。

READ ONLY

停止合同

验证命令 TTL、watchdog、STOP latch、断网/退出和人工接管；未确认停止保持 stop-pending。

STOP

有界运动

清场、低速、单一发布者、物理遥控/e-stop，记录首次响应与物理停止时间。

BOUNDED MOVE

业务闭环

一条路线、1–3 检查点、一次采集/告警、取消/恢复；通过后才扩大场景。

05 / NON-CLAIMS

五个常见误判

  1. 01同属 Go2 系列或使用相同 IDL，不代表 Air、Pro、EDU 与 Go2-W 的控制和传感器能力等价。
  2. 02App 中出现 3D 地图、巡逻或目标点，不代表存在开放、稳定、可自动化的 SDK 合同。
  3. 03Move() 返回 0 可能只表示本地请求发出；没有状态/物理响应，不能声称动作已接受。
  4. 04在线建图成功与冷启动固定地图重定位是两项能力，必须分别验收。
  5. 05社区 jailbreak、非官方固件或别的 SKU 成功案例不能替代采购合同、官方支持与本机实测。
