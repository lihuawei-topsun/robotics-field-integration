Evidence labels used here

LABELWHAT IT MEANSWHAT IT DOES NOT MEAN
CODE TRACEA behavior is directly visible in a linked public revision.It has not necessarily been reproduced on this integrator's hardware.
ENGINEERING INFERENCEThe explanation follows from code plus an observed state trace.It is not a confirmed root cause until the requested measurement is captured.
HIL PENDINGA bounded hardware-in-the-loop test is specified and still needs agreement or execution.No pass result, performance figure or deployment claim is implied.
FIELD VERIFIEDA result may use this label only after the exact hardware, configuration, route and acceptance record are preserved.A vendor video, simulation or adjacent robot model is not enough.
